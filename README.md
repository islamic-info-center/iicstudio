# IIC Studio

موقع حجز استوديو IIC ولوحة الإدارة.

- `site/` : ملفات الموقع كما هي (بدون بناء). Netlify ينشر هذا المجلد تلقائياً عند كل تعديل.
- `apps-script/` : كود Google Apps Script (الخلفية). يُنسخ `Code.gs` إلى محرر Apps Script ثم يُنشر من جديد.

كلمات السر ومفاتيح واتساب محفوظة في Script Properties داخل Apps Script، وليست في هذا المستودع.
